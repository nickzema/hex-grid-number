# Changelog

## 0.7.2 - Spacing, colors and logo
Owlbear's 15 starting colors with your own saved after them, selected-text colors, the real Zemaria crown-and-sword logo, even spacing in every mode, and the Map Location Keys layer fix.

## 0.7.1 - Map Location Keys fix
Hexes sent to Map Location Keys now sit on the layer it reads, and status messages fade away.

## 0.7.0 - Map Location Keys
Send every hex to Map Location Keys from a header button, Players moved to the bottom of the list, and the extra toolbar tool removed.

## 0.6.0 - Spiral start and colors
Pick where Ring and Spiral start and which way they go, Owlbear's own color swatches, Players moved up, a 500 square that shrinks to fit, and the Zemaria footer back.

## 0.5.0 - Ring and Spiral
Grid, Ring (a letter per ring) and Spiral numbering, bigger interface text in a 460 square, and real fonts in the preview.

## 0.4.0 - Owlbear look
Dark Owlbear-style panel laid out like the sketch, with a bigger sample hex and the Zemaria styling removed.

## 0.3.1 - Tour and layout
Zemaria help tour on the right, bigger sample hex, left controls rebuilt so nothing overlaps, double-click the rotate handle to straighten.

## 0.3.0 - Players, pickers and centering
SHOW / HIDE / OFF for players, Owlbear-style color pickers and handles, snap, negative starts, and labels centered on the hex.

## 0.2.0 - Template hex and toolbar
Preview hex you type the first key into, with a font, size, bold and italic toolbar and live redraw.

## 0.1.4 - Label styling
Columns run A-Z then AA. Start column defaults to A. Adds label font, size and position (top, middle, bottom).

## 0.1.3 - Single Set button
Set and Reset now use the selected token. Removed the map-click mode that did nothing.

## 0.1.2 - First hex from selection
Adds Use selected to set the first hex from a selected token, plus error messages when setting it fails.

## 0.1.1 - Manifest fix
Renamed `manifest` to `manifest_version` so Owlbear accepts the extension.

## 0.1.0
First version: hex numbering in AA.01 style.
- Set the first hex; set columns, rows, start column and row.
- Labels placed as locked items, GM-only or visible to players.
- Click any hex with the tool to read its key.
